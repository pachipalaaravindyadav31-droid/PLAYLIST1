Linear Models With vs. Without Scaling

Feature scaling using standard standardization ($z = \frac{x - \mu}{\sigma}$) is critical for linear models, especially when features have different ranges.

  • Without Scaling: The features with large scales (e.g. duration_ms in hundreds of thousands, tempo around 120) dominate the loss function optimization. The coefficients assigned are inversely proportional to their scale, making them uninterpretable. Test $R^2$ is extremely poor: {{ "%.4f"|format(scaling_metrics.unscaled_metrics.test.r2) }}.
  • With Scaling: All features are centered at mean 0 and variance 1. The coefficient weights directly reflect feature importance: a larger coefficient indicates a stronger relative impact on target popularity. Test $R^2$ jumps significantly to {{ "%.4f"|format(scaling_metrics.scaled_metrics.test.r2) }}.
Important: Distance-based estimators (like KNN or SVM) and regularized linear models (Ridge/Lasso) will fail or yield incorrect predictions without proper scaling.

Regularization Alpha Sweep (L1 vs. L2)

We analyzed the shrinkage behavior of coefficients under L1 (Lasso), L2 (Ridge), and Elastic Net (L1+L2 blend) penalty terms:

  • Ridge Regression (L2 Penalty): Adds a penalty on the squared magnitudes of the coefficients ($\lambda \sum w_i^2$). As alpha increases, weights shrink continuously toward zero, but never become exactly zero. This helps handle multicollinearity by distributing weight.
  • Lasso Regression (L1 Penalty): Adds a penalty on the absolute magnitudes of the coefficients ($\lambda \sum |w_i|$). Lasso drives less important features' coefficients to exactly zero, effectively performing automatic feature selection.
  • Elastic Net (L1 + L2): Blends both penalties, balancing weight distribution and feature selection.
Look at the Lasso plot on the right: as alpha increases past $0.1$, almost all features shrink to $0.0$, leaving only the most critical predictors active.

Decision Tree Overfitting Curve (Bias-Variance)

By varying the max_depth of a Decision Tree, we observe the classic bias-variance trade-off in action:

  • Underfitting Zone (Depth 1-4): The model has too few splits. Both training and testing error are high because the model is too simple to capture the relationship (High Bias).
  • Optimal Zone (Depth 5-7): Testing error reaches its minimum. The model generalizes well to unseen validation data.
  • Overfitting Zone (Depth 8-15): Training error drops toward zero, but testing error (MSE) begins to climb. The model is memorizing noise in the training set and fails to generalize (High Variance).
Ensemble Mitigation: Random Forests and Gradient Boosted trees reduce this overfitting tendency. Random Forest reduces variance via bootstrap aggregation (bagging), while Gradient Boosting reduces bias sequentially.

Tree Model Feature Importances

Ensemble tree models (Random Forest) let us extract the relative split importance of each feature. We compare the top features driving track popularity vs. user skip behavior:

  • Popularity Predictors: The top features are typically the track's genre encoding, loudness, duration_ms, and acousticness. Acoustic characteristics play a major role in classifying genres, which in turn strongly influence popularity.
  • Skip Behavior Predictors: The features danceability, energy, acousticness, speechiness, and valence carry the highest weight. This is expected as our skip proxy is mathematically defined by these active listening characteristics, and the Random Forest model successfully identified these underlying patterns!
