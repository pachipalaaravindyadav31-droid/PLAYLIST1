M2: Linear Models, Regularization Paths & Sigmoid Log-Loss

Ridge \(L_2\) vs. Lasso \(L_1\) & Logistic Regression

Analyzing how \(L_1\) regularization drives coefficients to exact zero (sparsity) while \(L_2\) shrinks weights smoothly to avoid multicollinear blowup.

L1 vs L2 Regularization Path (Alpha Sweep)

Geometric Insight: The diamond contour of \(L_1\) constraint \(\|\beta\|_1 \le C\) hits loss ellipses on axes, setting irrelevant audio feature weights to zero.

Impact of Feature Standardization on Coefficients

Standardization Necessity: Without z-score scaling, large-magnitude features (e.g. duration_ms in millions) dominate gradient descent and corrupt regularization penalties.

Alpha Hyperparameter Penalty vs. Test \(R^2\)

Bias-Variance Tradeoff: Optimal \(\alpha\) balances bias from coefficient shrinkage against variance from noisy empirical data.

Logistic Regression Decision Boundary & Confusion Matrix

Hyperplane Partition: Maps log-odds \(z = \beta^T x + \beta_0\) through sigmoid \(\sigma(z) = \frac{1}{1 + e^{-z}}\) with classification threshold \(p=0.5\).

M3: Tree-Based Ensembles & Boosting Dynamics

Random Forests (Bagging) & GBDT / XGBoost / LightGBM (Boosting)

Comparing tree growth depth, variance reduction through bootstrap aggregation (Random Forests), and sequential gradient residual fitting.

Decision Tree Max Depth vs Overfitting

Overfitting Diagnostic: As depth exceeds 10, Train \(R^2 \to 1.0\) while Test \(R^2\) collapses due to leaf memorization of track variance.

Tree Gini / MDI Feature Importance (Skip Classification)

Mean Decrease in Impurity: Ranks acoustic features (loudness, valence, tempo) by aggregate reduction in split impurity across all ensemble trees.

Random Forest Feature Importance (Popularity Regression)

Feature Selection: Genre one-hot embeddings combined with acoustic signals provide the strongest non-linear split nodes.

Multinomial 3-Class Risk Matrix

Multi-Class Evaluation: Softmax output distribution across Low (0), Medium (1), and High (2) skip risk tiers.

M4: Unsupervised Learning, PCA & Anomaly Detection

K-Means, DBSCAN, Hierarchical Dendrograms, t-SNE & Isolation Forest

Discovering natural song clusters, non-convex density groupings, outlier track signals, and 2D manifold embeddings without supervision labels.

K-Means Elbow Method & Silhouette Coefficient

Inertia (WCSS) & Silhouette: Optimal \(K\) is selected at the maximum silhouette \(s(i) = \frac{b(i)-a(i)}{\max(a(i), b(i))}\) and the elbow point where diminishing returns occur in within-cluster sum of squares.

PCA Scree Plot & Cumulative Explained Variance

Dimensionality Reduction: Eigenvalue decomposition of covariance matrix \(\Sigma = \frac{1}{n} X^T X\). Shows number of principal components needed to retain 85%+ audio variance.

DBSCAN Density Clusters & Noise Outliers

Density-Based Partition: Uses \(\varepsilon\) and \(minPts\) to identify arbitrarily shaped non-convex audio clusters and isolate outlier tracks with no cluster assignment (\(\text{label}=-1\)).

Hierarchical Clustering Dendrogram (Ward Linkage)

Agglomerative Tree: Bottom-up pairwise merging minimizing within-cluster variance (\(d(u,v) = \sqrt{\frac{|u||v|}{|u|+|v|}} \|c_u - c_v\|_2\)). Horizontal cut gives cluster hierarchy.

Isolation Forest Anomaly Detection

Path Length Anomaly Score: Isolates abnormal audio signatures (e.g. ambient noise, spoken word tracks) via random recursive feature splits. Outliers require significantly shorter tree depth \(h(x)\).

t-SNE 2D Manifold Embedding

Non-Linear Manifold: Minimizes Kullback-Leibler divergence between Gaussian pairwise affinities in high-D and Student-t in 2D space. Note: inter-cluster distances are not Euclidean.

M5: Model Evaluation, Selection, Calibration & Significance Testing

Platt Scaling, Isotonic Regression, ROC/PR Curves, Learning Curves & McNemar's Test

Rigorous statistical validation: ensuring predicted probabilities match true empirical event likelihoods, diagnosing sample complexity, and evaluating model superiority.

Reliability Diagram (Probability Calibration Curves)

Calibration Discipline: Compares Uncalibrated vs Platt Scaling vs Isotonic Regression against ideal \(45^\circ\) diagonal. Quantified via Brier Score \(\text{BS} = \frac{1}{N}\sum (f_i - y_i)^2\).

ROC-AUC vs Precision-Recall (PR-AUC) Curves

Class Imbalance Insight: While ROC can appear overly optimistic due to large true negative count, PR-AUC explicitly measures Precision against Recall relative to the base skip rate.

Learning Curve (Sample Complexity & Bias-Variance)

Data Scarcity Diagnosis: Tracks Train vs 5-Fold Stratified Cross-Validation F1-score across sample sizes \(N\). Convergence gap reveals remaining variance error.

McNemar's Statistical Test (Classifier Comparison)

Statistical Significance: 2x2 contingency matrix evaluating discordant predictions \(b\) (Model A correct, B wrong) vs \(c\) (Model B correct, A wrong). Test statistic \(\chi^2 = \frac{(|b - c| - 1)^2}{b + c}\).

Regression Loss Diagnostics & Residual Analysis (RMSE vs MAE)

Residual Normality & Outlier Sensitivity: Evaluates residual errors \(e_i = y_i - \hat{y}_i\). RMSE heavily penalizes large errors quadratically, while MAE measures median central tendency.
