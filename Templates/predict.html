Prediction Trace Flow
1. User Input
Audio features and genre entered in UI form.
2. Flask API Routing
AJAX POST request dispatched to endpoint /api/predict.
3. Schema Validation
Flask parses input JSON and verifies bounding numeric ranges.
4. Preprocessing Pipeline
Applies standardized scaling (Scaler) and creates one-hot sparse genre matrix.
5. Saved Model Inference
Joblib loads regression & classifier models to perform forward inference.
6. Telemetry & Log Ingestion
Inputs and outputs logged with timestamp to logs/predictions.csv.
7. UI Response Rendering
API returns JSON payload, and browser dynamically updates cards and progress bars.
