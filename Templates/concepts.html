Module 1: The Machine Learning System Lifecycle

In production systems, machine learning is not an isolated modeling notebook — it is an end-to-end engineering pipeline connecting data ingestion to real-time inference, persistent telemetry, and drift monitoring.

Training-Serving Skew Prevention

The most common production failure in ML occurs when feature transformations at inference time differ from those applied during training (Training-Serving Skew).

How PlaylistPulse solves it: We serialize the fitted StandardScaler and OneHotEncoder directly into Joblib artifacts during training. At inference time, app.py loads the exact same objects to transform user input, guaranteeing identical mean, variance, and one-hot column alignment without any feature mismatch.

End-to-End Prediction Trace

Every single-row prediction traces through a strict 7-stage deterministic execution pipeline:

  1. User Input: Audio characteristics entered via sliders and dropdowns.
  2. HTTP POST: AJAX payload sent to /api/predict.
  3. Validation: Type checking & boundary range assertions.
  4. Preprocessing: Scaling numerical values + One-Hot genre vectorization.
  5. Model Inference: Forward pass through loaded Joblib model.
  6. Telemetry Logging: Async write to logs/predictions.csv.
  7. Response Rendering: JSON response populates dashboard widgets.

Module 2: Supervised Learning — Linear Models at Depth

Linear models formulate prediction as a linear combination of input features: $\hat{y} = \mathbf{w}^T \mathbf{x} + b$. They offer strong interpretability, rapid training, and clear geometric properties.

1. Feature Scaling & Standardization

Transforming inputs using standard score: $z = \frac{x - \mu}{\sigma}$.

Without scaling, features with large numeric scales (such as duration_ms in hundreds of thousands) overpower the loss gradient, causing linear regression $R^2$ to collapse to 0.036. With StandardScaler, all features have unit variance, boosting test $R^2$ to 0.264 and making weights directly interpretable.

View Scaling Experiment
2. Regularization Geometry: L1 vs. L2

Constraining model complexity to prevent overfitting and multicollinearity:

  • Ridge ($L_2$): $\min \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda \|\mathbf{w}\|_2^2$. Spherical constraint smoothly shrinks coefficients toward zero without nullifying them.
  • Lasso ($L_1$): $\min \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda \|\mathbf{w}\|_1$. Rhombus constraint with sharp corners drives non-essential weights to exactly zero, performing automatic feature selection.
  • Elastic Net ($L_1 + L_2$): Combines $L_1$ feature selection with $L_2$ group selection.
View Regularization Paths
3. Binary Logistic Regression

Estimates skip probability via sigmoid activation: $P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T \mathbf{x}}}$.

Trained using Binary Cross-Entropy (Log Loss). Achieves 92.7% Test Accuracy and 0.973 ROC-AUC for binary skip behavior on Spotify audio tracks.

4. Multinomial Logistic Regression (Softmax)

Generalizes binary logistic regression to multi-class ($K=3$: Low, Medium, High Risk):

$$P(y=k|\mathbf{x}) = \frac{e^{\mathbf{w}_k^T \mathbf{x}}}{\sum_{j=1}^K e^{\mathbf{w}_j^T \mathbf{x}}}$$ Evaluated on the 3-class skip-risk category with Macro $F_1 = \mathbf{0.791}$ and Macro $\text{AUC} = \mathbf{0.948}$.

Module 3: Supervised Learning — Tree-Based Models & Ensembles

Tree models make orthogonal partition splits across feature space, capturing non-linear interactions without requiring normalization or monotonic feature transformations.

1. Decision Trees & Bias-Variance Curve

Greedy recursive binary splitting using MSE / Gini impurity.

By sweeping tree depth from $1$ to $15$, we empirically illustrate the Bias-Variance Trade-off:

  • Depth 1-4 (High Bias / Underfitting): Inability to capture true non-linear relationships; both train and test error are high.
  • Depth 5-7 (Optimal Trade-off): Minimum validation error and peak generalization.
  • Depth 8-15 (High Variance / Overfitting): Training error drops to near-zero while test MSE increases as the tree memorizes sample noise.
2. Random Forests: Bagging & Variance Reduction

Reduces variance of deep decision trees via Bootstrap Aggregation + Random Feature Subsampling.

For $B$ decorrelated trees each with variance $\sigma^2$ and pairwise correlation $\rho$, the ensemble variance is: $$\text{Var}(\bar{T}) = \rho \sigma^2 + \frac{1-\rho}{B} \sigma^2$$ As $B$ grows, variance drops significantly without increasing bias.

3. Boosting: Gradient Boosting, XGBoost, LightGBM

Sequential functional gradient descent fitting residuals of previous iterations.

  • Gradient Boosting: Fits new shallow trees to negative gradient of loss function.
  • XGBoost: Employs 2nd order Taylor expansion of loss + explicit tree complexity regularization.
  • LightGBM: Uses histogram-based feature bucketing and leaf-wise (best-first) tree growth for ultra-fast training on large tabular datasets.
4. Feature Importance & Tabular Dominance

Mean Decrease in Impurity (MDI / Gini Importance).

Extracting feature importances shows that danceability, energy, and acousticness govern skip behavior, whereas track genre and loudness dominate popularity. On structured tabular data, tree ensembles routinely outperform neural networks due to their invariant scaling and robust handling of mixed discrete/continuous spaces.
