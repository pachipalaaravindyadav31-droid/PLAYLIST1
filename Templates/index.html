PlaylistPulse ML Lifecycle

A complete visual mapping of the ML lifecycle components demonstrated inside this project, representing a production-grade ML engineering pipeline.

1. Data Ingestion

Spotify tracks dataset containing 114,000 records loaded from CSV file.

2. Prep & Proxy

Null values imputed. Synthetic skip proxies engineered using acoustic combinations.

3. Pipeline Scale

Standard scaling numeric inputs, one-hot encoding genres, and training/test splits.

4. Train & Tune

Grid alpha sweeps for regularized models and depth sweeps for tree estimators.

5. Model Serialization

Serializing fitted scalers, encoders, and predictive models using Joblib.

6. Monitoring & Logs

Prediction logger registers runtime requests, providing telemetry and data drift checks.
